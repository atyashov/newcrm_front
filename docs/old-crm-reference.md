# Старое приложение как источник требований

`D:/OSPanel/home/newcrm/OldCrm` содержит старое приложение, которое переносится на новую архитектуру. Пользователь обозначил его как фактическое ТЗ: при разработке разделов сверять поля и сценарии с ним, а API-контракт брать из нового Laravel-бэкенда в `D:/OSPanel/home/newcrm/app`.

## Наименования групп товаров в смете

Старый раздел: `modules/admin/views/outlay-group-name`, контроллер `modules/admin/controllers/OutlayGroupNameController.php`.
Это справочник наименований групп, а не сами группы конкретной сметы и не группы расходов. Форма содержит одно поле `name`, записи привязаны к подразделению.

Новый модуль: `app/Modules/Admin/OutlayGroupNames`. API: `admin/outlay-group-names`, методы GET/POST и PUT/DELETE с ID. Список возвращается в `data.items` с Laravel-пагинацией. Для списка и сохранения обязателен `subdivision_id`, поиск и сортировка идут по `name`. Максимальный размер страницы 100.

Фронтенд: `/outlay-groups`. Меню загружается с бэкенда; для ссылки на этот раздел использовать `path: outlay-groups`. Старые адреса `/outlay-group-names` и `/outlay-group-name` перенаправляют на новый адрес.

## Состав сметы

Миграция `OutlayGroups/Migrations/2026_09_21_000001_normalize_outlay_composition.php` заменяет JSON-состав на группы и строки. Форма отправляет `groups: [{id?, outlay_group_name_id, items: [{id?, product_id, price, quantity, description?, images?}]}]` вместе со сметой. Существующие ID сохраняются; отсутствующие в массиве группы и строки сервер удаляет. Порядок задаётся порядком массивов. Название товара сохраняется сервером как снимок; изменение цены в смете не меняет каталог.

Цена имеет 2 десятичных знака, количество 3. Итоги считает сервер; явно заданная сумма скидки приоритетнее процента. На фронте показан предварительный расчёт по тем же правилам округления.

В старом приложении `modules/admin/views/outlay/outlay-groups.php` использует `getFreeQuantity` на даты аренды. В текущем новом Products API есть только `quantity` и `unlimited`: доступности с учётом других смет пока нет. Форма показывает общий остаток, количество во всех группах текущей сметы и предупреждение о нехватке; для календарной доступности потребуется API бэкенда.
