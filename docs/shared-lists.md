# Общие списки

`src/components/AppList.vue` отвечает только за отображение списка: заголовки, строки, сортировочные кнопки и действия. Загрузка, фильтры, пагинация, открытие модалок и CRUD остаются в разделе.
`src/components/ListActions.vue` содержит единые кнопки просмотра, редактирования и удаления.
Все размеры, цвета, отступы и состояния тем находятся в `src/assets/scss/material-dashboard/custom/_lists.scss`.
Образец плотности — список физических лиц: текст 0.875rem, отступы ячеек 0.25rem 0.5rem, кнопки 22px, иконки 0.75rem, промежуток между кнопками 0.5rem.

## Использование

```vue
<AppList
  :items="items"
  :columns="columns"
  :get-sort-icon="getSortIcon"
  @sort="handleSort"
  @edit="handleEdit"
  @delete="handleDelete"
/>
```

Колонка: `{key, label, sortable?, fallback?, format?: (item) => string}`.
Сложные значения можно вывести через слот `#cell-KEY="{ item }"`.
Просмотр включается пропом `view`; `edit` и `remove` включены по умолчанию.
`disabled`, `editDisabled` и `deleteDisabled` блокируют соответствующие действия.
Ключ строки берётся из `item.id`, при его отсутствии — из индекса.
В общем списке не следует задавать локальные размеры текста/иконок или padding ячеек.

Подключено в физических и юридических лицах, ролях, меню доступа, способах оплаты, складах, группах товаров сметы, статусах сметы, кассах, расходах, займах, товарах и категориях. `DirectoryList` использует его для пользователей и подразделений.
Группы расходов сохраняют дерево `details`: родительская строка использует общие классы и `ListActions`, дочерние записи — `AppList`.

Dashboard, список смет, финансовый график и шаблонные демонстрационные карточки не используют этот компонент и не затронуты. Стили ограничены классами `app-list*`, глобальные стили Bootstrap не переопределяются.
